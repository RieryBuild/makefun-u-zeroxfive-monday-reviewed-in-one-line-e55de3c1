One line reviewing my own Monday, entered in the [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty on make.fun.

The line is **"Monday moved in on Sunday night, rearranged my sleep, and is now charging me rent."** — Monday as a squatter who never leaves: it slips in on Sunday night, rearranges my sleep, and then starts charging rent for the week it stole. The rent is the punch — the week takes your time and then bills you for it.

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. Standard library only.
